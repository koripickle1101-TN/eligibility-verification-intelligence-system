# Typography Update

EVIS now uses a high-contrast editorial display serif for recruiter-facing headlines while preserving Manrope for body copy.

- Body/UI: Manrope
- Brand colors unchanged: #FFFFFF, #000000, #FF8200
- Display weights reduced to avoid a bulky visual feel on mobile
- Large headlines, statement copy, KPI numerals, quotes, and signature-question treatments share the same editorial system
